# 图表与可视化（D3 等框架）

长卡允许引入图表库（D3、Observable Plot 等）来提高信息密度与观感，但要遵守三条：

1. **离线可用**：把库源码内联进 `card.html`（`<script>` 里放压缩版），不要引用 CDN——
   `render` 与 `audit` 都在 `file://` 下跑，交付后的卡片也要能离线打开。
2. **文字留在 HTML**：SVG 只画形状（路径、矩形、圆、网格线），标签、数值、图例、刻度全部用
   HTML 元素承载。`audit` 的文本测量基于 DOM Range，SVG `<text>` 量不到，字号下限与行宽检查
   会失效；放在 HTML 层才能让审计真正生效。
3. **图形与口径对齐**：图上每个可见量都要有 HTML 文字对应（图例、刻度、口径行），颜色与角度
   编码写进 `data-encoding`（例如「角度 = 案例数」），容器挂 `data-source-ref`。

许可与体积：库必须是可再分发的开源许可（D3 为 ISC），内联时保留版权头；D3 v7 压缩版约 280KB，
HTML 会因此变大，这是换取离线可渲染的代价。

已验证做法（2026-09-11，Anthropic 九月报告卡）：D3 v7.9.0 内联在 `card.html` 末尾，
同步绘制两个 SVG——44 起案例 × 7 领域的环形构成图，以及 2025-12 至 2026-08 的月份甘特图
（只画报告明确给出时间窗的案例）。中心数字、图例、刻度、口径全在 HTML 层；
`audit` 23 项全过，PNG 与「画布 × scale」逐像素一致。
